## 1. Single typed facade over generated bindings

`frontend/src/wails-service.ts` is the only file that imports the generated
bindings; components use the `DesktopService` it builds:

```ts
import { Events } from "@wailsio/runtime";
import * as bindings from "../bindings/github.com/blak0p/attack-shark-linux/internal/desktop/service";

export const desktopService: DesktopService = {
  GetSnapshot: bindings.GetSnapshot,
  StageDPI: bindings.StageDPI as DesktopService["StageDPI"],
  ...
  OnStatusEvent: (callback) => Events.On("mouse:status", (event) => callback(event.data)),
  OnConfiguration: (callback) => Events.On("mouse:configuration", (event) => callback(event.data)),
  OnPollingConfiguration: (callback) => Events.On("mouse:polling-configuration", (event) => callback(event.data)),
};
```

## 4. Live events with cleanup in `App.tsx`

`frontend/src/App.tsx:53` subscribes and returns the unsubscribe fn from the
effect, so listeners are torn down on unmount/re-subscribe:

```tsx
useEffect(() => {
  const unsubscribe = service.OnStatusEvent((event) => {
    setSnapshot((current) => (current && receivesEvent(selected.current, event) ? applyStatusEvent(current, event) : current));
  });
  return unsubscribe;
}, [service]);
```

## 5. TypeScript types mirror the Go DTOs (defined once in `App.tsx`)

`frontend/src/App.tsx:11` re-declares the DTO shape the UI consumes; the generated
`models.ts` is imported only for the `Binding` type:

```ts
export type DPIConfig = { DPI: number[]; ActiveStage: number; StageMask: number; LiftDistance: number; Colors?: number[][]; AngleControl?: boolean; RippleControl?: boolean };
export type Snapshot = { Connection: string; Battery?: number | null; Applied: DPIConfig; Pending: DPIConfig; Factory: DPIConfig; Revision: number; Error: { Code: string }; ... };
export type DesktopService = { GetSnapshot(): Promise<Snapshot>; StageDPI(config: DPIConfig): Promise<Snapshot>; ... };
```

`App.tsx` composes the panels and owns all state/effects
(`frontend/src/App.tsx:118`): it is the single place with business logic.
