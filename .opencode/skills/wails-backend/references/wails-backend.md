# wails-backend — integration references (real repo excerpts)

## 1. Compose the App and register one service

`cmd/x6configurator/main.go:54` builds the Wails `application.App`, registers the
backend service, and serves the embedded `frontend/dist`:

```go
// cmd/x6configurator/main.go:54
app := application.New(application.Options{
	Name: "Attack Shark X6 Configurator",
	OnShutdown: func() { stopListening() },
	Services: []application.Service{
		application.NewService(service),
	},
	Assets: application.AssetOptions{
		Handler: application.AssetFileServerFS(assets),
	},
})
```

Assets come from `//go:embed frontend/dist` (`main.go:20`).

## 2. Bridge events without importing Wails into `desktop`

The service emits through `EventSink`; `cmd` supplies the Wails emitter:

```go
// cmd/x6configurator/main.go:67
service.AttachListener(passive, wailsEventSink{app: app})
service.StartListener(listenCtx)
```

```go
// internal/desktop/service.go:981
func (s *Service) emitConfiguration(binding Binding, state *deviceState) {
	s.mu.Lock()
	sink := s.events
	s.mu.Unlock()
	if sink != nil {
		sink.Emit("mouse:configuration", ConfigurationEvent{Binding: binding, Snapshot: snapshotOf(state)})
	}
}
```

## 6. Bindings are generated — never hand-edited

`frontend/bindings/github.com/blak0p/attack-shark-linux/internal/desktop/models.ts:1`
carries the marker:

```
// This file is automatically generated. DO NOT EDIT
```

The frontend consumes them through a typed facade, not directly
(`frontend/src/wails-service.ts`):

```ts
import * as bindings from "../bindings/github.com/blak0p/attack-shark-linux/internal/desktop/service";
export const desktopService: DesktopService = {
  GetSnapshot: bindings.GetSnapshot,
  ...
  OnStatusEvent: (callback) => Events.On("mouse:status", (event) => callback(event.data)),
};
```
