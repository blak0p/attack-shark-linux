# Attack Shark Linux

Attack Shark Linux is a Linux read-only diagnostic CLI for the Attack Shark X6.

## Initial Scope

- Identify the X6 through Linux USB/HID interfaces.
- Display device information and other read-only diagnostic data.
- Document the device protocol before adding control features.

> **Warning:** This project sends no writes to the device. It does not change settings, profiles, firmware, lighting, macros, or any other device state.

The official Windows application is local reference material for research only. It is never part of this repository and must not be committed or uploaded.
